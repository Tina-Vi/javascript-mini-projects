# JavaScript Mini Projects

A collection of five small frontend projects built while learning HTML, CSS, and JavaScript

These projects focus on practicing DOM manipulation, event handling, form validation, animations, and browser APIs

## Projects

### 1. Calculator

[Live Demo](https://tina-vi.github.io/javascript-mini-projects/calculator/)

A simple calculator supporting basic arithmetic operations, decimal numbers, and percentage calculations

**Technologies:** HTML, CSS, JavaScript

### 2. Form Validation

[Live Demo](https://tina-vi.github.io/javascript-mini-projects/form-validation/)

A form with custom validation, error messages, and visual feedback

**Features:**

- Required field validation
- Input format and length validation
- Custom error messages
- Validation feedback and form submission handling

### 3. Typewriter Effect

[Live Demo](https://tina-vi.github.io/javascript-mini-projects/typewriter/)

An animated text display that simulates typing and deleting characters

**Features:**

- Character-by-character typing animation
- Randomized typing delays
- Automatic transitions between phrases

### 4. Modal Window

[Live Demo](https://tina-vi.github.io/javascript-mini-projects/modal-window/)

A shopping cart confirmation interface built with native HTML dialogs

**Features:**

- Confirmation and cancellation dialogs
- Opening and closing modal windows
- Closing dialogs using the Escape key or clicking outside

### 5. Multiframe Viewer

[Live Demo](https://tina-vi.github.io/javascript-mini-projects/multiframe/)

An interface for displaying up to eight websites in separate iframe elements

**Features:**

- Adding and replacing website URLs
- Clearing all frames
- Instructions displayed in a modal window

_Note: Some websites restrict iframe embedding through browser security policies_

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM API
- Browser APIs

## About

These projects were created as part of my frontend learning journey and demonstrate my early practical experience with JavaScript
